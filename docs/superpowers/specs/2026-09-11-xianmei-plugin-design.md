# nonebot-plugin-xianmei 设计文档

日期：2026-09-11
状态：已确认
背景：为 B 站主播「小小桃纸哟」（UID 6867955，39.4 万粉）的 QQ 群制作一款"向群主献媚"的娱乐插件。

## 1. 目标

群主（主播本人）在群里出现时，机器人自动发送一条谄媚彩虹屁。纯本地运行，零外部依赖（不调 LLM、不联网）。

## 2. 主播调研摘要（文案梗来源）

- 人设：自称「头部主播」「五冠王」，粉丝称「桃神」「小桃桃」「桃子」，她管粉丝叫「师傅」「徒弟」
- 内容轨迹：星露谷起家 → 星布谷地（"五冠王"称号来源）→ 2026 年主直播原神（「2026年还有纯萌新」实况系列），兼玩崩铁、绝区零
- 口头禅：「出货」「老演员」「好穷啊」「无情的XX机器」「大家堵门来」「求求求求关注！!」「抽到三点多」
- 直播时间：晚 8 点开播到困；直播间 live.bilibili.com/22725947
- 价值观梗：理性消费「不要花钱买资格」、拒绝道德绑架

## 3. 触发与频率机制

- 监听群消息，发送者 QQ == 该群已设置的群主 → 进入判定
- 冷却：距上次献媚超过冷却时间才再次触发，默认 30 分钟（可调）。群主连续聊天时冷却期内只触发一次
- 日封顶：每天累计最多 N 条，默认 5 条（可调），按自然日（本地时区）重置
- 触发时从文案库随机抽取 1 条发送
- 仅群主本人发言触发；他人 @群主或提到主播不触发
- 未设置群主 / 额度用完 / 冷却中 / 插件已停用 → 静默不响应
- 机器人自身消息、其他 bot 消息不触发

## 4. 命令（全部仅限 superuser）

| 命令 | 作用 |
|---|---|
| `献媚设置群主 <QQ号>` | 在当前群绑定群主 QQ |
| `献媚设置上限 <N>` | 设置每日封顶条数（正整数） |
| `献媚设置冷却 <分钟>` | 设置冷却时间（正整数分钟） |
| `献媚预览` | 随机发一条文案看效果 |
| `献媚状态` | 查看当前群配置与今日已发数量 |
| `献媚开关` | 启用/停用当前群 |

- 命令在群内发送，作用于当前群；私聊命令不生效
- 参数非法（非数字、超范围）时回复用法提示

## 5. 文案库（5000 条）

- 每条 10~30 字
- 风格：玩主播本人梗的跪舔彩虹屁；称呼随机（「桃神」「群主大人」「五冠王」「头部主播」）
- 梗素材：五冠王、头部主播、出货/老演员、堵门、抽到三点多、星露谷真爱、2026 年纯萌新、帮舰长抽卡、理性消费、求关注
- 生成方式：手工撰写约 50 个句式模板 × 语料槽位（称呼/成就/游戏事迹/夸张修辞）组合去重至 5000 条，生成后人工抽查修剪
- 存储：插件资源 YAML 文件，启动时加载进内存
- 验收标准：≥5000 条、无重复、长度合规（10~30 字）

## 6. 数据存储

- 每群独立配置，JSON 存放于 NoneBot 数据目录（`data/xianmei/`）
- 字段：`owner_qq` / `daily_limit` / `cooldown_minutes` / `enabled` / `last_trigger_ts` / `today_count` / `today_date`
- 多群互不影响

## 7. 架构

```
nonebot-plugin-xianmei/
├── nonebot_plugin_xianmei/
│   ├── __init__.py        # 插件入口、事件注册
│   ├── config.py          # 配置存储（每群 JSON 读写）
│   ├── trigger.py         # 触发判定（群主匹配/冷却/日限）
│   ├── commands.py        # superuser 命令
│   └── quips.py           # 文案库加载与随机抽取
├── resources/quips.yaml   # 5000 条文案库
├── tests/
└── pyproject.toml
```

- 三个核心模块（config / trigger / quips）相互独立，commands 依赖 config
- Python 3.10+，NoneBot2 + nonebot-adapter-onebot

## 8. 测试

- pytest 覆盖：触发判定（群主匹配、冷却、日限、自然日重置）、命令权限（非 superuser 拒绝）、文案库完整性（≥5000、无重复、长度合规）
- 项目已有测试先例（用户其他插件均含 tests/），按同惯例

## 9. 明确不做（YAGNI）

- 不调用 LLM 或任何外部 API
- 不响应他人提及主播的消息
- 不做文案"当日不重复"去重（5000 条池子 vs 每日 ≤N 条，重复概率可忽略）
- 不做多群主、不做事迹更新（不抓直播状态）
